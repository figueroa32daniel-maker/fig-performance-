# Case study photos

Drop a before/after here named after the client's page slug, then run
`cd _build && python3 build_case_studies.py` (and `build_case_jonathan.py`
for Jonathan).

    ray.jpg  matt.jpg  linda.jpg  eric.jpg
    jenna.jpg  natalie.jpg  rosa.jpg  chris.jpg  jonathan.jpg

Naming the file IS the pairing. It is the statement that this photograph
is that client, so it is Dan's to make, not something to infer from the
order files happened to arrive in. A page with no file renders no image
rather than a broken one.

Before any of these go up, the client has to have agreed to appear by name
next to their numbers. Agreeing to an uncaptioned photo in the homepage
track is a different thing and does not cover this.

Roughly 16:9 and about 960px wide suits the layout.
